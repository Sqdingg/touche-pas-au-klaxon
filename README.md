# Touche pas au klaxon — Application de covoiturage inter-sites

Application permettant aux employés de proposer et consulter des trajets de covoiturage entre les différents sites de l'entreprise.

## Prérequis

- PHP 8.2+
- Composer
- MySQL ou MariaDB
- Node.js + npm (pour compiler Sass/Bootstrap)
